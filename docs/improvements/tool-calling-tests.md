# ツール呼び出しのテスト追加

LLM ワーカーが各ツール（`extract_text`, `goal_driven_synthesis`, `persist_knowledge_tree`, `grep_search` など）を想定通りに呼び出せているかを確認するテストを追加する。

## 課題
現在、ツールの内部ロジックに対する単体テストは一部存在するが、「LLM エージェントが意図したタイミングと引数でツールを適切に呼び出しているか」を検証する統合的なテストが不足している。

## 方針
- LLM のモック（または軽量なモデル）を使用し、特定のプロンプト・入力に対してエージェントが正しいツールを選択し、正しい引数を渡して実行しているかをアサートするテストを作成する。
- 新規追加されるツール（FUSEを活用した `grep_search` など）も含め、全ツールの呼び出しカバレッジを確保する。
