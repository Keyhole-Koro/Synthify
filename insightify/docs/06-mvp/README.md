# MVP

Insightify の価値を最小構成で検証する計画を扱う。

予定する主文書:

- `product-scope.md` — v1 user story、in-scope、non-scope
- `prototype-plan.md` — fixture を使った FlowFold interaction prototype
- `demo-scenario.md` — Google login 追加を題材にした end-to-end demo
- `evaluation-plan.md` — layout、context、proposal、completion evidence の評価指標
- `delivery-gates.md` — 各 phase の開始・完了条件

最初の prototype は Agent の高度な自律性より、Portal/Room と anchored collaboration の有用性を検証する。
