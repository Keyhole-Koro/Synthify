# Collaboration

Flow 上の場所へ結び付いた人間と AI の対話を扱う。

予定する主文書:

- `anchored-thread-design.md` — Anchor、Thread、message、Decision、Open Question
- `thread-memory-spec.md` — 構造化 memory、supersedes、要約 checkpoint
- `context-compiler-design.md` — Graph/Artifact context の選択、優先順位、provenance
- `proposal-intent-spec.md` — answer、search、graph change、artifact change、decision request

read-only conversation と mutation-capable Agent Run は service 境界で分離する。
